# 💒 Dharmesh & Neha Wedding App

A Progressive Web App (PWA) for wedding coordination and guest management.

## 🌟 Features

- 📱 **Mobile-First PWA** - Install on any device
- 🌐 **Multilingual** - English, Hindi, Gujarati
- 🔐 **Role-Based Access** - Admin, Coordinators, Family, Guests
- 📅 **Event Schedule** - Full wedding timeline
- 🍽️ **Meal Information** - Daily menus
- 🏨 **Venue Details** - Maps & directions
- 👥 **Team Coordination** - Task management

## 🔧 Local Development

1. Clone the repository
2. Open `index.html` in a browser, or
3. Run a local server:
   ```bash
   python3 -m http.server 3000
   ```
4. Visit `http://localhost:3000`

## 📦 Deployment

This app is deployed on GitHub Pages. Any push to the `main` branch will automatically update the live site.
